Executive summary

SahuAI Agent is an all-in-one AI orchestration platform that aggregates frontier models from global providers into a single interface. It works as an intelligent consensus engine — routing queries through parallel expert models, synthesising their outputs through staged reasoning pipelines, and returning answers that are more accurate and balanced than any single provider could produce alone.

Modes

  • SahuAI — standard consensus chat across your selected models.
  • Search — agentic loop: the model decides what to search, re-searches, scrapes pages and answers with citations.
  • Deep Research — five-stage pipeline with 24 expert roles and a super-master aggregator.
  • Artifacts / Task — full single-file HTML & React apps with live preview and canvas.
  • Study — Socratic tutor that guides instead of giving answers away.
  • Travel Planner — grounded itineraries with budget tables and booking tips.

Agent skills

  • Web Search / Scrape / Fetch / Browse — multi-engine research with per-engine selection.
  • Code Interpreter — sandboxed Python (Pyodide) and JavaScript with npm imports.
  • File Creation — PDF, DOCX, XLSX, PPTX, MD, CSV, JSON download cards.
  • Live Preview — sandboxed app window with console, phone width and open-in-tab.
  • MCP tools — real current date/time and an exact calculator engine.
  • Agent Swarm — 2–10 parallel workers, spawnable as many times as needed.
  • Skill Creator — the model can define new reusable skills with their own toggles.

Reasoning effort

DeepThink exposes an effort ladder — Off, Low, Medium, High (default), X-High, Max — mapped onto provider-native thinking parameters and token ceilings so deeper effort genuinely means deeper reasoning.

Privacy

API keys, chats, pinned messages and skills are stored only in your browser's local storage. Incognito mode keeps nothing at all.

Model configuration

Pick the models you want to use. Use ⇣ Fetch to load the live model list from any provider, then select what you need. Selected models answer in parallel; consensus merges them.
