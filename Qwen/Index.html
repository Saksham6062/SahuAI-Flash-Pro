📋 Executive Summary

SahuAI Agent is an all-in-one AI orchestration platform that aggregates 57+ cutting-edge AI models from 18+ global providers into a single, intuitive interface. Built and led by Saksham Sahu under Saksham Intelligence, it delivers unlimited access to premium AI capabilities without managing multiple API keys or subscriptions.

Rather than a single-model chatbot, SahuAI acts as an intelligent consensus engine — routing queries through parallel expert models, synthesising their outputs through advanced reasoning pipelines, and returning answers that are more accurate, balanced and contextually aware than any single provider could produce alone.

🧭 Core capabilities

  • Agentic web loop — the model decides what to search, re-searches, scrapes, fetches and browses until satisfied.
  • MCP tools — real current date/time and an exact local calculator.
  • Agent Swarm — spawn 2–10 parallel worker agents, any number of rounds.
  • Code interpreter — sandboxed Python (Pyodide) and JavaScript with npm imports.
  • File creation — PDF, DOCX, XLSX, PPTX, CSV, MD, JSON, TXT and ZIP.
  • Live preview — HTML and React apps render in a sandboxed window with console.
  • Deep Research — 5-stage pipeline with expert roles and a final synthesiser.
